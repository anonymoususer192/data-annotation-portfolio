# Artifact upload guide

This repository currently contains the project landing page, attribution, annotation guidelines, class summary, and QC documentation.

The downloadable project bundle also contains the compressed-or-full COCO annotation exports and before/after preview images. Those binary/preview assets are not committed in this repository revision. To include them directly on GitHub, upload the contents of `projects/01-vehicle-detection/annotations/` and `projects/01-vehicle-detection/previews/` from the extracted bundle to the matching paths. Do not upload all 30 source images; the source dataset is linked in the attribution file.
