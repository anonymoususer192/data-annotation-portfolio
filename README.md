# Data Annotation Portfolio

**Vinsentius Davis Anggara** · Aspiring AI Data Annotator

This repository documents self-directed practice in data annotation, labeling consistency, export handling, and quality checks. These are personal practice projects, not paid client work.

## Project 01 — Vehicle Detection

- 30 traffic-camera images annotated with bounding boxes in CVAT.
- 159 annotations in the raw CVAT export.
- Five label categories defined: `car`, `motorcycle`, `bus`, `truck`, `person`.
- The documented reviewed copy excludes one likely false-positive `person` annotation; the raw export is preserved separately for transparency.
- COCO JSON format, annotation guidance, QC notes, source attribution, and before/after previews are included in the project folder.

See [Project 01 — Vehicle Detection](projects/01-vehicle-detection/README.md).

## Tools

- CVAT — manual bounding-box annotation
- COCO JSON — annotation export
- Python — structural validation and preview generation
- GitHub — project documentation

## Transparency

This is an entry-level personal portfolio. Counts and outcomes refer to the documented 30-image subset. Structural checks do not guarantee semantic correctness for every box; the QC notes explain the limits of the review.
